🚀 Personal Portfolio Website
A modern, responsive personal portfolio website built with Next.js, React, TypeScript, Tailwind CSS, and Framer Motion.

The website uses a space-inspired interactive design with animations and a custom astronaut-themed opening experience to present my professional profile in an engaging way.

🌐 Live Website
View Portfolio

✨ What's Inside
Hero Section — Introduction, professional focus, social links, and key metrics
About Section — Personal profile, education, certifications, and achievements
Skills Section — Categorized technical skills and technologies
Projects Section — Featured projects with descriptions, technologies, GitHub links, and live demos
Experience Section — Education and professional experience presented as a timeline
Contact Section — Contact form, email, GitHub, and LinkedIn
Interactive Space Theme — Animated starfield, astronaut elements, and space environment
Responsive Design — Optimized for desktop, tablet, and mobile devices

🚀 Run Locally
git clone https://github.com/MadhavKotak-24/Portfolio-Website.git
cd Portfolio-Website
npm install
npm run dev
Then open http://localhost:3000.
